Установка занимает минут пятнадцать, из которых десять вы просто ждёте. Ничего знать заранее не нужно: если вы никогда не ставили Linux, начните с первого раздела.

## Что понадобится

- **Сервер.** Подойдёт самый дешёвый VPS: 2 ГБ оперативной памяти, 10 ГБ диска. Это примерно 200–400 рублей в месяц у любого хостинг-провайдера.
- **Домен.** Например, `example.com`. Купить можно там же, где сервер, или у любого регистратора.
- **Полчаса времени.**

> Сайты, которые вы сделаете, будут жить на этом же сервере. Второй сервер для второго сайта не нужен.

## Шаг 1. Debian на сервере

Yulia рассчитана на **Debian 13 (Trixie)**. Не Ubuntu, не CentOS — именно Debian: так все команды в этой документации совпадают с тем, что происходит у вас.

### Если вы берёте VPS у провайдера

Так проще всего, и это рекомендуемый путь. При создании сервера провайдер спросит операционную систему — выберите **Debian 13**, 64-битную версию. Через минуту-две сервер готов, и провайдер покажет:

- **IP-адрес** — четыре числа через точку, например `203.0.113.10`;
- **пароль пользователя root** — или предложит загрузить SSH-ключ.

Больше на панели провайдера делать нечего.

### Если вы ставите Debian сами

Это нужно, только если сервер стоит у вас физически.

1. Скачайте образ с [debian.org/download](https://www.debian.org/download) — файл вида `debian-13.x.x-amd64-netinst.iso`.
2. Запишите его на флешку. На Windows — программой [Rufus](https://rufus.ie), на macOS и Linux — командой `dd`, или [balenaEtcher](https://etcher.balena.io) на любой системе.
3. Загрузите компьютер с флешки. Обычно для этого при включении нажимают <kbd>F12</kbd>, <kbd>F2</kbd> или <kbd>Del</kbd> — какую именно, пишет сам компьютер в первые секунды.
4. Выберите **Install** (не Graphical install — он тут ничего не добавляет).
5. Дальше установщик спрашивает язык, страну, раскладку — отвечайте как удобно.
6. **Имя компьютера** — любое, например `yulia`. **Домен** можно оставить пустым.
7. Придумайте пароль root и запишите его. Обычного пользователя можно тоже завести.
8. **Разметка диска** — выберите «Авто — использовать весь диск». Если на диске были данные, они пропадут.
9. **Выбор программ** — снимите все галочки, кроме **SSH server** и **standard system utilities**. Графическая оболочка на сервере не нужна и только съест память.
10. Согласитесь установить загрузчик GRUB на диск. Готово.

## Шаг 2. Домен смотрит на сервер

Это тот шаг, который чаще всего делают неправильно, поэтому сделайте его **до** запуска установщика.

Решите, по какому адресу будет открываться админка. Обычно берут поддомен: `admin.example.com`.

Зайдите в панель управления доменом у регистратора, найдите раздел **DNS-записи** и добавьте запись:

| Поле | Значение |
|---|---|
| Тип | `A` |
| Имя (host) | `admin` |
| Значение (value) | IP-адрес вашего сервера |
| TTL | оставьте по умолчанию |

Сохраните. Изменение расходится по интернету от минуты до нескольких часов — обычно минут пять.

Проверить можно на своём компьютере:

```bash
ping admin.example.com
```

Если в ответ видно IP вашего сервера — всё готово. Установщик проверит это ещё раз и не даст промахнуться.

## Шаг 3. Подключение к серверу

С вашего компьютера — из «Терминала» на macOS и Linux, из PowerShell на Windows:

```bash
ssh root@203.0.113.10
```

Подставьте свой IP. При первом подключении спросят, доверяете ли вы этому серверу — ответьте `yes`. Потом попросят пароль root.

> Пароль при вводе не отображается — ни точками, ни звёздочками. Это нормально: печатайте вслепую и нажимайте <kbd>Enter</kbd>.

## Шаг 4. Один пакет

Установщик Yulia написан на Ruby, поэтому Ruby и нужен — больше ничего. Одной командой:

```bash
apt-get update && apt-get install -y ruby curl
```

Всё остальное — Docker, база данных, веб-сервер — поставит сам установщик.

## Шаг 5. Установщик

```bash
curl -fsSL https://raw.githubusercontent.com/emostr/yulia/main/InstallYulia.rb -o InstallYulia.rb
sudo ruby InstallYulia.rb
```

Откроется экран с рамкой и меню. Двигайтесь стрелками <kbd>↑</kbd> <kbd>↓</kbd>, выбирайте <kbd>Enter</kbd>, выходите <kbd>Ctrl</kbd>+<kbd>C</kbd>.

Установщик по очереди:

1. проверит, хватает ли памяти и места;
2. спросит домен админки и **проверит его по DNS** — если запись ещё не разошлась, он честно скажет об этом и предложит проверить снова;
3. спросит почту для Let's Encrypt (туда придёт письмо, если сертификат когда-нибудь будет истекать);
4. поставит Docker;
5. скачает Yulia;
6. сгенерирует пароли и ключи — вам их придумывать не нужно;
7. соберёт и запустит всё;
8. дождётся, пока приложение ответит.

Занимает это пять–десять минут, почти всё время — скачивание.

> Если что-то прервалось, просто запустите скрипт снова. Он **идемпотентен**: продолжит с того места, где остановился, и ничего не сломает повторным запуском.

## Шаг 6. Первый вход

Когда установщик скажет «Готово», откройте в браузере на **своём** компьютере:

```
https://admin.example.com
```

Дальше — [первые шаги](/yulia/ru/first-steps/): вы придумаете логин и пароль, привяжете второй фактор и попадёте в админку.

**На сервер возвращаться больше не нужно.** Даже для обновлений — см. [Обновление](/yulia/ru/updating/).

## Если хочется попробовать локально

Ставить сервер, чтобы посмотреть, — необязательно. На своём компьютере, если есть Docker:

```bash
git clone https://github.com/emostr/yulia.git
cd yulia
cp .env.example .env
# Ключ подписи кук: без него приложение не стартует
sed -i '' "s/^SECRET_KEY_BASE=$/SECRET_KEY_BASE=$(openssl rand -hex 64)/" .env
docker compose up -d --build
```

Админка откроется на `http://localhost:8080`. Доменов и сертификатов в этом режиме нет — сайты смотрят по адресу `/preview/<адрес-сайта>`.
