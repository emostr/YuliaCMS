Готовых блоков хватает большинству сайтов. Но если нужно что-то своё — расписание, калькулятор, карточка товара, — блок можно написать самому. Прямо в админке, не заходя на сервер.

Блоки бывают двух видов:

- **HTML** — шаблон, который отрисовывает сервер. Рекомендуемый путь: быстро, работает без JavaScript, [дружит с htmx](/YuliaCMS/ru/htmx/).
- **[Svelte](/YuliaCMS/ru/svelte/)** — настоящий компонент, если нужна сложная логика в браузере.

Эта страница про первый.

## Где

**Блоки** → **HTML + htmx**. Откроется окно: слева описание блока и его поля, справа шаблон.

## Шаблон пишется на Liquid

Не на ERB и не на Ruby. [Liquid](https://shopify.github.io/liquid/) — язык шаблонов, придуманный ровно для этого случая: его пишет пользователь, а выполняет чужой сервер.

Причина простая. Одна установка Yulia держит несколько сайтов. Если бы блок мог выполнять Ruby, редактор одного сайта получил бы полный доступ к серверу и ко всем остальным сайтам на нём. Liquid этого не умеет — и не научится.

Практически это ограничение почти не мешает: Liquid умеет подставлять значения, условия, циклы и фильтры, а больше блоку обычно и не нужно.

## Что доступно в шаблоне

| Переменная | Что в ней |
|---|---|
| `block.<ключ поля>` | значение поля, которое ввели в редакторе |
| `block.id` | уникальный номер этого блока на странице |
| `site.name`, `site.url`, `site.locale` | о сайте |
| `page.title`, `page.path` | о странице |
| `form.action`, `form.csrf_token` | для форм |

## Всегда экранируйте

```liquid
{% raw %}{{ block.title | escape }}{% endraw %}
```

Фильтр `escape` превращает `<` и `>` в безопасный текст. Без него посетитель, увидевший на странице чужой скрипт, получит его выполнение — а вы получите взломанный сайт.

Исключение одно: поле типа «форматированный текст». Его Yulia уже очистила на сервере, и его выводят без `escape` — иначе вместо оформления читатель увидит теги.

## Поля

Поле — это то, что редактор покажет в панели справа. У каждого есть ключ (латиницей, по нему обращаются в шаблоне), подпись и тип.

| Тип | Что показывает |
|---|---|
| `text` | однострочное поле |
| `textarea` | много текста |
| `richtext` | полноценный редактор с форматированием |
| `number` | число |
| `boolean` | переключатель |
| `select` | выбор из списка |
| `image` | выбор из медиатеки |
| `link` | ссылка |
| `color` | цвет |

## Пример целиком

Блок «Часы работы»: заголовок и список строк.

**Поля:** `title` (text), `note` (textarea).

**Шаблон:**

```liquid
{% raw %}{% comment %}
  Часы работы. `note` может быть в несколько строк - фильтр newline_to_br
  превращает переносы в <br>, иначе они схлопнутся в пробелы.
{% endcomment %}
<section class="y-features">
  <h2 class="y-features-title">{{ block.title | escape }}</h2>

  {% if block.note != blank %}
    <p>{{ block.note | escape | newline_to_br }}</p>
  {% endif %}
</section>{% endraw %}
```

## Классы оформления

Пользуйтесь готовыми классами — тогда блок будет выглядеть как часть сайта и подхватит его тему и акцентный цвет:

| Класс | Что это |
|---|---|
| `y-features` | секция с отступами |
| `y-features-title` | заголовок секции |
| `y-feature` | карточка |
| `y-button y-button-solid` | кнопка заливкой |
| `y-button y-button-outline` | кнопка контуром |
| `y-figure` | картинка с подписью |
| `y-cols-2`, `y-cols-3`, `y-cols-4` | сетка в столбцы |
| `y-align-center` | по центру |

Цвета доступны через CSS-переменные: `var(--ng-accent)`, `var(--ng-ink)`, `var(--ng-muted)`, `var(--ng-line)`, `var(--ng-surface)`.

## Как посмотреть, как написаны встроенные блоки

Все блоки Yulia написаны на том же Liquid и лежат в репозитории в каталоге [`backend/app/blocks`](https://github.com/emostr/YuliaCMS/tree/main/backend/app/blocks). Это не спрятанный код — это примеры, которые можно читать и копировать.

## Если блок сломан

Шаблон с ошибкой не роняет страницу: сломанный блок просто не рисуется, остальные остаются на месте. Так одна опечатка не стоит посетителю всей страницы.
