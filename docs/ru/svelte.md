Блок на [Liquid с htmx](/YuliaCMS/ru/htmx/) закрывает почти всё. Но иногда нужна логика **внутри браузера**, без обращения к серверу: калькулятор, конструктор, интерактивная схема. Для этого есть блоки на Svelte.

> Это не «более продвинутый» путь, а другой. Если задача решается htmx — решайте htmx: получится быстрее и без JavaScript у посетителя.

## Как это работает

Блок на Svelte становится **островом**: сервер рисует на странице пустое место, а рядом подключает бандл именно этого блока. Бандл оживляет своё место и не трогает остальную страницу.

Из этого следует главное: **страница без такого блока не грузит ничего**. Один остров — один запрос. Остальной сайт остаётся обычным HTML.

## Компонент собирается на сервере

Когда вы сохраняете блок, Yulia собирает его прямо на вашем сервере — там для этого есть компилятор. Ждать нечего, ставить ничего не надо, доступ к серверу не нужен.

Пока сборка идёт, блок помечен как «собирается» и его нельзя поставить на страницу. Если компилятор ругнулся, ошибка показана в окне блока целиком, как её выдал компилятор, — по ней видно, в какой строке опечатка.

## Пример

**Блоки** → **Svelte**. Поля объявляются так же, как у блока на Liquid, и приходят в компонент как props.

Поле `title` (text) и `start` (number):

```svelte
<script>
  // Значения полей приходят как props.
  let { title = 'Счётчик', start = 0 } = $props();

  // Svelte 5: реактивное состояние объявляется руной $state.
  let count = $state(Number(start) || 0);
</script>

<div class="y-features">
  <h2 class="y-features-title">{title}</h2>

  <button class="y-button y-button-solid" onclick={() => count++}>
    Нажато {count} раз
  </button>
</div>
```

## Что нужно знать про Svelte 5

Yulia использует **Svelte 5**, в котором вместо старого синтаксиса появились руны. Если вы читаете статью или пример трёхлетней давности, сверьтесь:

| Svelte 3–4 | Svelte 5 |
|---|---|
| `export let title` | `let { title } = $props()` |
| `let count = 0` (реактивно само) | `let count = $state(0)` |
| `$: doubled = count * 2` | `let doubled = $derived(count * 2)` |
| `on:click={...}` | `onclick={...}` |
| `$: { ... }` побочный эффект | `$effect(() => { ... })` |

## Оформление

Классы сайта (`y-button`, `y-features`, `y-cols-3`) доступны и внутри острова — стили сайта загружены на странице. Пользуйтесь ими, и блок не будет выделяться чужеродно.

Свой `<style>` внутри компонента тоже работает, Svelte ограничит его этим компонентом.

## Чего остров не может

- **Обернуть собой страницу.** Остров живёт на своём месте в потоке блоков, между соседями.
- **Отрисоваться на сервере.** Пока бандл не загрузился, на месте острова пусто. Не кладите туда текст, который должен попасть в поиск, — для текста есть обычные блоки.
- **Дотянуться до базы.** Компонент работает в браузере посетителя. Данные он может только запросить у сервера, как любой другой скрипт.

## Что выбрать

| Задача | Чем делать |
|---|---|
| Форма обратной связи | встроенный блок «Форма» |
| Показать ещё записей | htmx, `hx-swap="beforeend"` |
| Поиск по ходу набора | htmx, `hx-trigger="input changed delay:500ms"` |
| Вкладки, аккордеон | htmx или обычный HTML (`<details>`) |
| Калькулятор, конструктор | Svelte |
| Интерактивная схема, редактор | Svelte |

## Размер

Каждый остров самодостаточен: он несёт в себе всё, что ему нужно, и весит порядка 30–40 КБ. Два разных острова на одной странице — это два бандла.

Это осознанный размен: самодостаточный бандл проще и надёжнее общей библиотеки, а платят за него только те страницы, где остров действительно стоит.
