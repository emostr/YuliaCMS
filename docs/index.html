Свободная CMS

Сайт, который вы соберёте сами

Yulia — это WordPress, каким он мог бы быть сегодня: визуальный редактор, который понятен без обучения, установка одной командой и сервер, на который больше не нужно возвращаться.

Как поставить Исходный код
$ curl -fsSL https://raw.githubusercontent.com/emostr/YuliaCMS/main/InstallYulia.rb -o InstallYulia.rb $ sudo ruby InstallYulia.rb

Что вы получаете

Не конструктор с сотней настроек, а короткий набор вещей, каждая из которых работает.

Визуальный редактор

Страница собирается из блоков: обложка, текст, галерея, форма. Блок настраивается в панели справа, порядок меняется перетаскиванием.

Богатый текст с формулами

Заголовки, списки, цитаты, картинки — и LaTeX прямо в тексте, с предпросмотром и сотней готовых заготовок.

Черновик и публикация

Посетитель всегда видит опубликованную версию. Правки живут отдельно, пока вы не нажмёте «Опубликовать».

Много сайтов на одном сервере

Второй сайт — это кнопка в админке, а не вторая установка. У каждого свой домен и свой сертификат.

HTTPS без вашего участия

Направьте домен на сервер и впишите его в админке. Сертификат Let's Encrypt выпускается сам, при первом обращении.

Свои блоки, когда нужно

Готовых блоков не хватило — напишите свой на HTML с htmx или компонентом Svelte. Прямо в админке, без доступа к серверу.

Как это происходит

От пустого сервера до работающего сайта — четыре шага.

Ставите Debian

Обычный образ у любого хостинг-провайдера. В документации расписано, что нажимать, если вы делаете это впервые.

Запускаете InstallYulia.rb

Скрипт спрашивает домен админки, проверяет его по DNS, ставит всё остальное сам и показывает понятный интерфейс вместо потока команд.

Заходите на свой домен

Придумываете логин и пароль, привязываете второй фактор — и попадаете в админку. Больше на сервер возвращаться не нужно.

Собираете сайт

Блоки, текст, картинки, домен. Кнопка «Опубликовать» — и сайт открыт для всех.

Почему сайт получается быстрым

Один путь рендеринга: страницу собирает сервер. Браузер получает готовый HTML.

Страница текста — ноль килобайт JavaScript

Скрипты подключаются только там, где они действительно нужны. Статья с картинками не платит за фреймворк.

htmx там, где нужен интерактив

Форма отправляется без перезагрузки страницы, а вы не написали ни строчки на JavaScript. Если JavaScript отключён — форма всё равно работает.

Svelte островами

Нужен настоящий компонент — он собирается в отдельный остров и загружается только на тех страницах, где стоит.

Из чего сделано

Ничего экзотического: скучные, проверенные вещи последних версий.
